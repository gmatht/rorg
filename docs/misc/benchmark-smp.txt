Benchmark is on a Intel(R) Core(TM) i7-10875H with a nvme ssd.
We see that 1x thread SMP is similar to original serial code.
The CPU is a 8 CPU 16 thread CPU. Exceeding the number of CPUS
can improve performance, be we see little point in exceeding
the number of CPU threads (i.e. 32x does not outperform 16x).
